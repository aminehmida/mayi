Eleventh alpha: AWS sign-ins. Agents get the temporary keys of one role, at the level you set for that role, and never the session that reaches all of them.

## AWS sign-ins

- **Add one in the app: Secrets, Add, AWS Sign-In.** Mayi suggests the portals your AWS CLI already knows. Your browser opens AWS's own sign-in, with your usual login and two-factor; AWS's page says Mayi is asking. Allow it, then choose which roles agents may use.
- **Each role is a profile with its own level.** Mayi suggests read-only roles at 1, roles that can change production at 4 and the rest at 3; change any with one click. A level 4 profile asks for Touch ID, your Apple Watch or your password for every use, with the AWS command in the dialog.
- **The AWS CLI, Terraform and the SDKs work as before.** Mayi adds a profile per role to `~/.aws/config` (`aws s3 ls --profile mawaqit-production-ro`), and the prompt shows the AWS command that asked. `mayi run --aws mawaqit/production-ro -- …` works too, and `mayi list` shows the profiles.
- **The AWS CLI's plain-file sign-in goes away.** The session the AWS CLI keeps in `~/.aws/sso/cache` can be read by any program, agents included. Mayi removes it for the portals it holds, and warns if `aws sso login` brings it back.
- **Sessions refresh silently, as with the AWS CLI.** When AWS ends one (after 8 hours by default), the next request asks you to sign in again, and carries on once you have.
- **Approving one profile never covers another.** An approval for the session is kept per profile and level.
- **Other machines:** `mayi aws setup` writes the same profiles on a server or another Mac paired with Mayi; nothing is stored there. A level 1 profile used from there notifies you once per agent session, not at every `aws` command.
- **On the phone too:** add an AWS sign-in from the Add sheet (Secret, Login, AWS), change its profiles, sign in again when a request waits, and approve level 4 profiles with your fingerprint. A sign-in added on either device reaches the other with the next sync.

## Asking less now asks for your finger

Lowering a secret's level, adding an expected command or a website, lengthening its approvals, or adding an AWS profile or lowering its level now asks for Touch ID (or the phone's fingerprint), even with Mayi's window unlocked. An agent that can drive your screen can no longer loosen a secret by itself.

## Limits

- Level 4 on an AWS profile is a check, not encryption: one sign-in serves all its roles, so it cannot be encrypted for one of them. Details in the [threat model](../threat-model.md#aws-sign-ins).
- A command you approve can keep its role's keys until they expire, 1 to 12 hours, as your AWS administrators set it.

## Updating

Update every device: devices before alpha.10 cannot read a vault holding an AWS sign-in. Quit Mayi on the Mac, `brew upgrade --cask mayi`, and allow the keychain prompt when Mayi starts. Update the phone through Obtainium, and `mayi` on other machines (`brew upgrade mayi-cli`) for `mayi run --aws` and `mayi aws setup`.
