Second alpha: a phone that already has your vault can now add a new Mac, and the Mac no longer starts a vault of its own without asking.

## Changes

- **Join from either side.** A new device can now show a code that the device holding the vault scans. On a Mac with no vault, the setup window shows it as a QR code under "Join Your Vault"; on the phone, Devices, "Add device" scans it or takes it as text. The old way (the device with the vault shows an invitation, the new device scans or pastes it) still works.
- **The Mac asks before creating a vault.** On first launch it shows the setup window: join your vault, paste an invitation from another Mac, or create a new vault.
- **Way out for a Mac that already made an empty vault.** Devices shows "Join Another Vault…": Mayi sets the empty vault aside and restarts into setup. It refuses if the vault holds anything.
- **Add a Device on the Mac** also takes the code a new device shows, so two Macs can join each other either way round.

## Updating

Quit Mayi on the Mac, then `brew upgrade --cask mayi`. Obtainium offers the phone update. If your Mac made its own empty vault with alpha.1, open Devices and choose "Join Another Vault…", then on the phone choose Add device and scan the Mac's code.

## Still alpha

The limits listed for alpha.1 still apply. In addition, a phone cannot show a code yet, so two phones cannot join each other without a Mac.
