Ninth alpha: requests show the program that will really run, and the Mac app's keys work only for Mayi.

## Requests

- **The program is shown by its full path** (`/opt/homebrew/bin/gh pr list`), in the prompt and in Activity. `mayi` looks it up itself and runs exactly that file, and does not look in the working folder or temporary folders, so a program an agent dropped there cannot pass for `gh`. A tool that lives only in the project is given by its path (`./node_modules/.bin/eslint`).
- **Expected commands written by name (`gh *`) match only programs found that way.** A program given by path is asked about, unless an expected command names that path.
- **The command runs without the variables that make programs load other code** (`DYLD_*`, `LD_PRELOAD`, `BASH_ENV`, `NODE_OPTIONS`, `PYTHONPATH`, git's command hooks and similar), as sudo does.

## The Mac app's keys

- **The app's Secure Enclave keys are sealed with a keychain item only Mayi can read.** Before, any program running as you could use them to decrypt every secret below level 4, without a request, a prompt or a line in Activity. Mayi now also uses the hardened runtime, so no program can load its code into it.
- **Until Mayi is signed with an Apple Developer ID, macOS asks once after each update** whether Mayi may use that item: type your password and choose Always Allow.

## Fixed

- The Mac app could quit if a `mayi` went away at the moment the app answered it.

## Mayi and agent sandboxes

The README and the threat model now say plainly where Mayi stands: it decides which secrets an agent may use, asks you, and records every use; it does not stop an agent that has been compromised from keeping a value you let it use. For agents you cannot fully trust, run them in a sandbox with a network policy (Docker's agent sandboxes, OpenShell) and keep the secrets that matter most at level 4.

## Updating

Quit Mayi on the Mac, then `brew upgrade --cask mayi`, and allow the keychain prompt when Mayi starts. Update `mayi` on other machines too (`brew upgrade mayi-cli`), so their requests show the full path.
