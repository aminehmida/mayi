Third alpha: fixes for the traps found in a review of the whole experience.

## Agents

- **"Allow for This Session" now works with Claude Code.** Each of its commands runs in a new shell, so every command counted as a new session and you were asked again each time. The session is now the agent's own process, shown in prompts as, for example, `claude (pid 43271, since 09:14:02)`. A sign-in over several pages asks once, as intended.
- **Paired machines keep the address that worked**, such as a Tailscale name, a tunnel or a forwarded port, and try it first. Before, the first request replaced it with the device's own addresses, and the next request could fail.

## Mac

- **Touch ID is no longer required.** Pairing, adding devices, recovery keys and level 4 secrets accept Touch ID, an Apple Watch or your login password, so a closed lid does not block them. This applies to a Mac whose vault is set up from alpha.3 on; an existing vault keeps its fingerprint-only key until it is set up again.
- **Always reachable:** Mayi shows in the Dock while its window is open, and opening it from Finder or Spotlight shows the window, even when the notch hides the menu-bar icon.
- **Starts at login**, with "Open at Login" in the menu to turn it off. The menu shows the version.

## Phone

- **Everything the Mac does:** edit secrets and logins, pair machines, invite or remove devices, make a recovery key, and show a code so that a new phone can be added by another one.
- **Serves again after a restart**, without being opened.
- **Warns when notifications are off**, since requests in the background could not reach you.
- **Asks before creating a vault**, and offers "Join another vault" while its vault is empty.
- Fixed a crash when Android started the app in the background.

## Updating

Quit Mayi on the Mac, then `brew upgrade --cask mayi`. Obtainium offers the phone update.
