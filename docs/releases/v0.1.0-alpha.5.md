Fifth alpha: easier editing, and two-factor codes instead of keys.

## Both apps

- **An eye button on every value field** shows what you typed, to check it before saving. Fields start hidden every time.
- **Logins show their two-factor code, never the key.** Once you show a login's values, the current code appears with a countdown and a copy button. The key behind it stays hidden, and saving keeps it.
- **Replace or remove the two-factor key.** Type or paste a new key into "New two-factor key", scan its QR code on the phone, or on the Mac copy the QR code (Control-Shift-Command-4) and paste it with the QR button. The new key's code shows before you save, so you can check it. "Remove two-factor key" drops it.
- **Fixed:** typing only a new password into a saved login dropped its username and two-factor key. A saved login's values can now be changed only once shown, so whatever you do not retype is kept.

## Updating

Quit Mayi on the Mac, then `brew upgrade --cask mayi`. Obtainium offers the phone update.
