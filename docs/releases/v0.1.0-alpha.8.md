Eighth alpha: folders and search, warnings on secrets to replace, and one activity log across your devices.

## Secrets

- **Search** the Secrets list by name, website or folder, on the Mac and the phone.
- **Folders.** A secret can go in one folder, typed or picked when you add or edit it. The Mac lists folders in its sidebar under Secrets; the phone shows them as filters above the list.
- **Secrets to replace are marked ⚠️.** When you remove a device or revoke a machine, every secret it could read or was given shows a warning on all your devices. Open the secret to see who may still have it and what to do. Saving a new value clears the warning; Dismiss clears it if the value needs no replacing.

## Requests

- **The machine asking stands out**: its name and key in an orange capsule at the top of the request, on the Mac and the phone.
- **Tapping a request's notification on the phone opens the request,** whichever tab Mayi was on.
- **A revoked machine is told at once.** Its request stops with "Pair it again" instead of retrying until it times out.
- A request from a terminal outside an agent is named "terminal", with the shell as its session.

## Activity

- **One log across your devices.** Each device sends what it recorded to the others when they sync, so any of them shows every request, which machine made it and which device answered. Entries are kept for 90 days.

## Fixed

- **The phone's scanner showed no picture** when opened from a secret's edit sheet. It now opens above the sheet.
- **The Mac asks for Touch ID as soon as Mayi opens,** not when its window is first shown.
- **The recovery key field** stays on one line, and Command-V pastes into it (the app had no Edit menu).

## Removed

- **The MCP server (`mayi mcp`).** Agents use Mayi through their shell with `mayi run` and the skill; an MCP tool would give apps without a shell a way to run commands on your Mac.

## Updating

Quit Mayi on the Mac, then `brew upgrade --cask mayi`. Obtainium offers the phone update. Update both: a device on alpha.7 neither sends nor receives activity, and does not show folders or warnings set elsewhere.
